# RaceDay - Event Management System (Part 3 POE)

## Project Overview
**RaceDay** is a South African road running, walking, and cycling event management system designed to coordinate event participation, categories, route details, secure user registration, and official race results. The platform supports two primary user roles: **Organisers** and **Participants**.

## Repository Structure & Part 1 Deliverables
Initial planning documents and database setup scripts are stored in the `docs/` directory:

* **Section A (ERD):** Entity Relationship Diagram (`/docs/Section A (ERD).pdf`)
* **Section B (API Endpoint Plan):** Specification of RESTful routes, request payloads, and expected responses (`/docs/Section B (ENDPOINT).pdf`)
* **Section C (Database Script):** Relational T-SQL database setup script (`/docs/RaceDay.sql`)
* **POE Answer Sheet:** Project response documentation (`/docs/POE Answersheet.pdf`)
